## Сейчас работаю над

### Сервис структурированного извлечения данных из PDF

REST API, преобразующий PDF-документы в типизированный JSON: текст по страницам,
метаданные, геометрия документа и найденные таблицы.

**Уже реализовано:** FastAPI, PyMuPDF, Pydantic, валидация файлов, тесты,
покрытие кода, Dockerfile и CI.

**Следующие этапы:** OCR для сканов, извлечение по JSON Schema с помощью LLM,
ссылки на страницы-источники, confidence score и evaluation-набор.

> Репозиторий проекта появится здесь после завершения первого публичного релиза.
